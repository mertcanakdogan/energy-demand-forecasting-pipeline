### Added

- Clean-room synthetic smart-meter data generation with deterministic quality events.
- Structured validation, gap/duplicate preparation, and calendar features.
- Seasonal-naive, weighted baseline, Holt-Winters, and SARIMAX forecasts.
- Leakage-safe rolling backtests, WAPE/MAE scoring, and per-meter model selection.
- Next-24-hour meter, group, and portfolio forecasts with anomaly reporting.
- Behavioural pytest suite, Python 3.12 GitHub Actions workflow, example outputs, charts, and demo notebook.
